# Chainguard Libraries for Go

Demo projects and resources for Chainguard Libraries for Go.

| Project | Description |
| --- | --- |
| [Chainguard Go Bank](go-bank/README.md) | A local banking demo with a Go API and an embedded web interface. It demonstrates module downloads through Chainguard and remediation of a JSON parser vulnerability. |
| [tools](tools/README.md) | Configuration and `chainctl` command examples for consuming Chainguard Libraries for Go, with commands to confirm access from a workstation or CI job. |

Configure access to Chainguard Libraries for Go, directly or through a
repository manager, using the commands and configuration in
[`tools`](tools/README.md).

Then start with the [setup instructions](go-bank/README.md#go-setup). Use the
[demo steps](go-bank/demo/readme.md) to compare the vulnerable and patched
module versions.
